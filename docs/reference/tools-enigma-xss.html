Enigma XSS

Autonomous XSS detection engine using a 5-rotor methodology for systematic WAF bypass

An autonomous XSS engine that probes, learns what the WAF blocks, and systematically works through bypass cascades until it finds execution. It doesn’t guess — it asks questions, observes answers, and adapts.

# The 5-Rotor Methodology

Like the original Enigma machine, XSS bypass is the product of five independent decisions — each a “rotor” with multiple positions:

  1. Context — Where does input land? (HTML, attribute, script, href, SVG)
  2. Blockers — What is the WAF blocking? (Binary search decomposition)
  3. Encoding — How should characters be represented? (HTML entities, JS unicode, URL)
  4. Structure — What syntax carries the payload? (Parentheses bypass, DOM clobbering)
  5. Execution — How does the JavaScript fire? (onerror, ontoggle, popover API)

The engine learns from every blocked payload. By the 20th attempt, it has a detailed model of the WAF’s behaviour and navigates a narrowing possibility space with increasingly precise information.

# Usage

# Basic reflected XSS scan
enigma run "https://target.com/search" "q"

# With authentication
enigma run "https://target.com/search" "q" --cookie="session=abc123"

# DOM XSS via URL hash
enigma run "https://target.com/#" "hash" --source=hash

# Stored XSS with observation
enigma run "https://target.com/comment" "comment" \
  --observe="https://target.com/post/123"
